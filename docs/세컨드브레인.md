
- **결과:** 각 결과에 **내용·출처·조건·미확인**이 통째로 붙어 나오고, `record`(파일#id)가 함께 나온다. 조건과 미확인을 잘라 내지 않는다.
- **용도:** 내부 작업용이다. 검색 결과는 정책 판정이 아니고, 고객에게 그대로 전달하지 않는다.

## 한계

- **동의어를 모른다.** "다른 사람"은 "타인/타 계정"으로, "녹았다"는 "해동/이탈/온도"로 바꿔 검색한다. 동의어 사전은 만들지 않았다(마감 범위 밖).
- **결과는 후보다.** 점수가 높아도 조건·미확인을 읽어야 한다. 하나의 사실로 결론 내지 않는다.
- **id 없는 항목:** 기존 runtime 일부 항목에는 id가 없어 `record`가 `파일#순번`으로 나온다. 순번은 파일이 바뀌면 달라질 수 있다.
- **중복:** `interview-progress.json`과 runtime에 같은 취지의 문장이 따로 있으면 둘 다 나온다(예: 미래 무조건 약속 불가).
- 원본·판독 노트 본문은 검색하지 않는다. 검수된 JSON만 검색한다. 원문은 `출처`를 따라가서 본다.
