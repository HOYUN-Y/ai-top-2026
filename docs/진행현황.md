# 교동마을 산지직송 — 문제와 진행 현황

최종 갱신: 2026-10-31 14:20 KST. 감독 갱신 문서다. 실시간 발송 상태는 [인터뷰 색인](../interviews/INDEX.md), 구현 세부는 [구현 보고](../coordination/implementation.md), 가능한 일·금지·이관은 [에이전트 업무범위](에이전트-업무범위.md)를 확인한다.

## 문제 상황

대회 속 기준일은 **2037년 6월 30일**이다. 2037년 3월 2일 개점한 「교동마을 산지직송」은 제주 농촌 교동마을의 농산물과 어촌 갯마을의 위탁 수산물을 함께 판매한다. 교동마을 청년회는 온라인 판매·고객 응대·홍보·프로모션·체험 행사를 나누어 맡고, 갯마을 조합은 수산물을 공급한다.

판매와 CS를 전담하던 이민준은 늘어난 고객 문의를 감당하기 어렵다. 배송·환불·상품 정보가 조합 문서, 홍보물, 운영 기록, 생산자·배송 담당자의 기억, 과거 상담과 예외 처리에 흩어져 있다. 같은 사건도 사람마다 아는 범위와 관점이 다르다.

우리 역할은 민준의 친구이자 원격 AX 전문가다. 관계자의 **비즈니스 상황·처리 기준·책임·예외·사례**를 인터뷰해 지식을 모으고, 근거에 맞게 짧고 정확히 답하며 필요한 조회·환불·이관을 실제 수행하는 카카오톡 고객 응대 AI를 완성한다. 인터뷰에서는 기술 명세를 직접 요구하지 않는다.

## 평가·운영 조건

- 핵심 지식 획득 수, 말풍선 응답 p95, 평균 말풍선 수, 말풍선당 평균 글자 수, 응답 정확도와 필요한 업무 실행을 평가한다. 배점은 비공개다.
- 사용자 안내 기준 질문은 **건당 200자 이하, 관계자별 최대100회**다. 첫 라운드는 신규 일반 질문 총10회·인당5회 이내로 제한하고 최소20회 여유를 남긴다. 상태 명령은 별도 기록한다.
- 관계자는 총10명이며 이름 목록은 제공되지 않는다. **이민준·고길동·홍이장·구방만·홍보라·김청년·박수복·박민아·홍보걸 9명**의 채널·접근·직접 업무 답변을 확보했다. 박민아는 사용자가 홍이장에게 갯마을→교동 인도 담당을 물어 연결했고, 갯마을 배정 시원배송 기사이며 조합 직원이 아니다. 문귀남·최덕만·하동철은 조직 관계도상 직접 문의 대상이 아닌 생산자이며 대리 진술로 확인한다. 마지막1명은 미확보이며 마감에 맞춰 탐색을 종료했다. [연락처 획득 경로와 관계도](지식지도.md)가 정본이다.
- 참가자 서버는 **현실 시간 2026년11월1일24:00(KST)**까지 응답해야 한다. 이야기 속 날짜와 혼동하지 않는다.
- 제출 후 수정·재제출이 불가하므로 최종 제출 전에 실제 카카오톡 왕복과 업무 실행을 점검한다.

## 인터뷰와 문서 검토 원칙

1. 대회 안내에 따라 관계자마다 보유 지식·경험·권한과 답변 방식이 다르고, 답변에는 기억·의견·추측이 섞일 수 있음을 전제로 한다. 이름 목록은 제공되지 않는다. 한 사람의 모름을 전체 관계망의 부재로 확대하지 않는다. 담당자의 **직접 아는 사실과 결정할 권한**을 구분한다. 배송 현장 사실을 운영자에게 추측하게 하거나 공급자에게 환불액을 결정하게 하지 않는다.
2. 질문은 실제 고객 상황 하나를 중심으로 한다. 기술적 API·명세 질문은 하지 않는다. 답변에 관련 근거가 나오면 그 자료를 따라간다.
3. 감독이 수신인·문구·200자 제한·목적·기존 자료와 중복 여부·담당 범위 적합성을 확인한 뒤 발송한다. 응답 지연으로 재전송하지 않는다.
4. 질문·답변 원문, 전송 시각, 횟수, 첨부, 확인된 사실, 조건·예외, 미확인을 분리한다. 요약과 원문을 대조한다.
5. 같은 사건의 관점 차이와 근거 충돌을 보존한다. 고객에게 안내할 정보와 내부 판단용 정보를 구분한다.
6. 로그인·인증·권한 차단·토큰 누락 등 사용자 조치가 필요한 문제는 즉시 알린다. 새 관계자 채널 추가가 필요하면 이름·역할·링크를 바로 전달한다. 자료를 다시 내려받거나 정리하느라 사용자가 인터뷰를 중단할 필요는 없다.

## 진행 과정

- 기존 캡처와 고길동 권한 위임표를 판독해 승인 순서·금액 예외·과거 약속 처리 등을 정리했다.
- 처음에는 자료·연락망을 한꺼번에 요청했으나 두 관계자가 업무를 좁혀 달라고 답했다. 이후 목적을 좁혀 홍이장·구방만 채널을 확보했다.
- 이민준에게 주문 조회API 명세를 직접 요청한 것은 질문 방향의 오류였다. 사용자 지적과 실제 답변에 따라 기술 문의를 중단하고 비즈니스 상황 중심으로 수정했다. 이 질문은 반복하지 않는다.
- 홍이장에게 수산물 하자 상황을 묻자 인도 온도·책임 경계 설명과 위탁계약서가 나왔다. 문서를 먼저 요구하지 않아도 업무 질문에서 근거를 확보할 수 있음을 확인했다.
- 구현·독립 검수로 재접속, 대기 작업, 지식 갱신 경계 오류를 수정했다. 실제 게이트웨이 인증과 모델 호출은 확인했지만 봇 상시 운영·실제 액션은 완료되지 않았다.
- 사용자 요청에 따라 네 인물의 지식 범위를 연결하는 Opus 지식 지도 세션을 추가했다.

## 연락망 확장과 수집 속도 개선

- 고길동이 업무분야별 담당자/연락창구 제공 의사를 밝혀 미상 인물 연결의 중심으로 활용한다.
- 홍보라·김청년 링크를 확보했고 사용자가 추가한 채팅도 확인했다. 새 링크는 감독이 사용자에게 전달하고, 채널 추가는 사용자가 가능하면 휴대폰에서 진행한다.
- 인터뷰는 질문·원문·횟수·링크 수집, 자료 Opus는 첨부 판독, 지도 Opus는 업무별 질문 설계, 검수는 중복·담당범위 확인을 병렬로 수행한다.
- [연락망 확장 승인 문구](../coordination/contact-expansion.md), [미상 인물 연결 경로](../coordination/contact-routes.md), [인물별 심층 질문 대기열](../coordination/interview-queues.md).
- 1차10회 이후 2차를 별도 집계하며 라운드당10회/인당5회, 전체 개인별100회/최소20회여유를 계속 지킨다. 라운드 예산 자체는 모든 질문의 자동 발송 승인이 아니다.

## 다음 작업

1. [업무별 수집 현황](지식지도.md)의 10개 영역을 심층 인터뷰한다. 사용자 요청으로 김청년의 인원변경 요금·최초예약·현장사고 질문을 우선 진행했다. 예약 조건은 확보했고 인원 감소 요금은 김청년·고길동·이민준 모두 확답하지 못해 같은 순환 질문을 종료했다. 수산물 안전 상신·협찬 미이행의 세부는 담당자도 모른다고 답했다. 수박 라벨·물류 재개·체험·카탈로그·개인정보·정기배송·증빙은 원문 대조해 반영했다. 새 인물·자료 경로를 따라가되 같은 연락처 순환 질문은 반복하지 않는다.
2. 첨부자료 전체 색인·누락 대조와 판독을 인터뷰와 병렬 진행한다. 확인된 사실은 원문 위치·조건·미확인과 함께 에이전트 지식에 반영한다.
3. 관계자별 직접 아는 사실·전달 증언·정책 결정권을 나눈다. 박민아 새 연결을 반영하고 남은2명을 탐색한다. 역할이나 자료 속 이름만으로 인터뷰 가능한 사람이라고 세지 않는다.
4. 확보한 근거를 봇에 반영하고, 실제 카카오톡 왕복·필수 업무 실행·운영 지속성을 점검한다.
5. 미확인 사항을 해결하고 최종 제출 자료·디브리프를 준비한다.

- 사용자가 저장한 `대화자료/` 원본은 이동하거나 덮어쓰지 않는다. 기존 `interviews/sources/`, `research/` 자료와 해시로 대조한다.
- [자료 목록](자료목록.md)에서 제공자·질문·원본 URL·로컬 파일·판독·누락 상태를 한 번에 찾는다. 기계용 목록은 [source-manifest.json](../research/source-manifest.json)이다.
- 원문 대화는 `interviews/sources/round*-transcript.json`, 첨부 원본과 판독은 목록의 경로에 보존한다. 아직 받지 못한 참조문서는 이미 확보한 자료와 구분한다.
- [지식 지도](지식지도.md)는 누가 어떤 사실을 알고 무엇을 결정하는지 연결한다. [구조화 지식](../interviews/knowledge.json)은 사실·출처·적용 조건·불확실성을 담아 기존 봇이 읽는다.
- 첨부 원본이나 내부 정산 정보를 그대로 고객에게 전달하지 않는다. 사건 기록은 당시 관측 사실이며 현재 주문 조회 결과나 처리 완료 증거를 대신하지 않는다.
- 지금은 기존 Markdown·JSON 구조를 사용한다. 자료를 찾기 위해 별도 데이터베이스를 설치할 필요가 없다.
