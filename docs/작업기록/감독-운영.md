## 맡은 일과 조율

인터뷰, 구현, 검수, 지식지도, 디브리프 담당을 나누고 파일 소유 범위와 검수 결과를 조율했다. 질문은 관계자의 실제 업무·경험·권한에 맞추도록 수정했고, 기술 API 명세는 관계자가 아닌 대회 공식 안내에서 확보했다. 자료의 원문·해석·추측·미확인을 구분하고 반영 여부를 확인했다.

자료 29개, 관계자 9명, 감독 문답 72건 등은 팀 기록을 집계한 수치다. 모든 대회 지식을 확보했다는 뜻은 아니다. 마지막 관계자 1명과 일부 참조 원문은 미확보로 남았다. [자료목록](../자료목록.md), [지식지도](../지식지도.md), [업무범위](../에이전트-업무범위.md)를 함께 사용한다.

## 최종 통합과 선택

- 검수된 지식 255건과 초기 지식 11건을 실제 봇이 읽는 두 JSON으로 통합했다. 실행 사본과 저장소의 지식 파일·bot.py가 동일한 것을 확인했다.
- 전체 지식을 모델 프롬프트에 넣는 방식을 유지했다. 지식 검색 CLI는 내부용이며, 동의어 검색 누락 사례가 있어 고객 봇의 선택 검색에 연결하지 않았다. 검색 자체의 속도를 고객 응답 속도 개선으로 주장하지 않았다.
- OpenRouter를 통해 `google/gemini-2.5-flash`를 사용한다. 액션 도구 40종을 활성화했으나 실제 업무를 변경하는 POST·환불 처리는 검수 중 실행하지 않았다.
- 모델의 함수 호출 오류를 다루는 도구 인자 평면화와 검수 결과를 통합했다. 검수 담당의 테스트·모델 평가를 확인하고, 모의 결과와 실제 외부 실행을 구분했다.
