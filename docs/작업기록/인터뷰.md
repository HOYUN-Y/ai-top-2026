# 인터뷰 담당 작업기록

대상: 2026-10-31 대회 인터뷰·자료 수집 세션. 아래 시각은 한국시간(KST)이다. 이 문서는 종료 후 기존 기록을 읽어 작성했으며, 새 인터뷰·UI 조작·API 호출·검증을 수행한 기록이 아니다.

## 목적과 기록 범위

관계자의 실제 업무·정책·판단 근거를 수집하고, 고객 상담용 지식으로 사용할 수 있도록 질문과 답변 원문, 자료 URL, 연락 경로, 질문 사용량을 보존하는 역할을 맡았다. 카카오톡 조작은 인터뷰 담당에게 배정됐으며, 감독이 검토한 정확 문구만 발송했다.

재개 시 인계받은 요약과 원본에는 R1~R4 총40문답이 이미 완료돼 있었다. 이40건은 재발송하지 않고 대조·보존한 선행 산출물이며, 이번 기록에서 새로 수행한 발송으로 주장하지 않는다. 이후 직접 추가한 일반 질문은 **R5 10건·R6 4건·R7 10건·R8 8건, 합계32건**이다. 최종 에이전트 원문72건은 선행40건을 포함한 누적이다. 사용자가 직접 보낸 것으로 확인되거나 외부 발신으로 관측한 일반 질문9건은 별도로 저장했다.

첨부 전체 판독, 지식 큐레이션, 서비스 구현·운영, 최종 제출은 다른 담당의 작업이었다. 특히 `interviews/knowledge.json` 소유가 감독에게 넘어간 뒤에는 편집하지 않았다. 모델 변경도 감독이 수행했고, 이 담당은 변경 완료 통보를 받아 같은 문맥에서 계속했다.

## 직접 수행한 작업과 산출물

- **승인 질문 발송과 수신 보존:** 수신인 제목·입력창·기존 발신을 확인하고 질문을 한 번씩 보냈다. 발신 말풍선 확인 직후 원문·시각을 저장했으며, 긴 답변은 전체 보기로 펼쳐 회수했다. [R5 원문](../../interviews/sources/round5-transcript.json), [R6 원문](../../interviews/sources/round6-transcript.json), [R7 원문](../../interviews/sources/round7-transcript.json), [R8 원문](../../interviews/sources/round8-transcript.json)이 직접 추가 수집의 정본이다.
- **사용자 발신과 예산 분리:** 사용자가 직접 보낸 status·목록 질문과 후속 문답을 [외부 관측 원문](../../interviews/sources/external-observed-messages.json)에 보존했다. 사용자 발신 확인 후 발송자 표기를 정정했고, 이미 반영한 사용량을 다시 더하지 않았다. status와 제출봇 테스트는 NPC 일반 질문에서 제외했다.
- **연락 경로 확인:** 소개자·업무 목적·정확 URL·사용자 추가·데스크톱 접근·직접 응답을 각각 기록했다. 박민아는 홍이장 사용자 문답을 통해 연결됐고, 홍보걸은 조직 관계도의 홍보 목적 소개 경로를 근거로 승인 질문을 보내 연결했다. [연락처와 출처](../../interviews/sources/contacts.json), [박민아](../../interviews/박민아.md), [홍보걸](../../interviews/홍보걸.md)에 결과를 남겼다. 채널 추가는 사용자가 수행했다.
- **첨부와 진행 문서 동기화:** 새 첨부는 URL과 제공자·문항을 [첨부 intake](../../interviews/sources/attachment-intake.json)에 즉시 저장했다. 상세 판독을 기다리지 않고 다음 승인 질문으로 이동했다. [INDEX](../../interviews/INDEX.md), [NEXT](../../interviews/NEXT.md), 인물별 문서와 [R8 기록](../../interviews/ROUND8.md)을 원문·카운터에 맞춰 갱신했다.
- **질문 초안:** 공개 고객 사례15개와 기존 질문54개를 읽어 업무 상황 중심 후보6개를 [업무 공백 후보](../../coordination/interview-api-gaps.md)에 작성했다. 이 초안 자체를 발송 승인으로 취급하지 않았고, 이후 감독이 따로 승인한 문구를 따랐다.

R5~R8에서 새로 받은 주요 자료에는 체험 운영 기준, 상품 카탈로그, 정기배송 약관, 증빙 발행 기준, 개인정보·제3자 보호·조합 규정, 과거 행사 목록, 사업자정보 공시, 택배사 계약, 온도 로그, 부분환불 임계표, 축제 매대 전단, 조직 관계도가 있다. 이는 **수신·URL 보존 실적**이며, 각 문서의 정적 판독과 사실 검수 실적은 자료 담당에게 귀속된다.

## 주요 판단과 이유

1. **재시도보다 발신 확인을 우선했다.** 화면 변경 오류가 나면 최신 화면을 다시 읽고 기존 말풍선과 빈 입력창을 확인했다. 오류가 났다는 이유만으로 같은 질문을 다시 보내지 않았다. 사용자 직접 조작으로 생긴 발신을 자동화 장애나 내 발신으로 단정하지 않았다.
2. **비즈니스 상황으로 범위를 좁혔다.** 선행 기록의 기술 명세 요구는 잘못된 질문 방향으로 인계돼 있었다. 이를 반복하지 않고 고객 문제, 담당 업무, 판단·책임·예외·근거를 묻는 승인 문구만 사용했다. 한 질문에 여러 자료나 전체 명부를 묶어 요구하지 않았다.
3. **모름과 부재를 구분했다.** 담당자가 연락처나 기준을 모른다고 해도 인물·정책이 없다고 결론내리지 않았다. 체험 인원 감소 정산처럼 김청년→고길동→이민준→김청년으로 돌아오는 경로는 미확인 상태로 닫고 반복하지 않았다.
4. **기억·기록·권한을 구분했다.** 박민아의 운송 시각·경고음 경험은 본인 진술로 보존하고 온도 로그·원인 판정과 구분했다. 홍보걸은 마지막에 스크립트·캡처·자료 위치를 제공할 수 없으며 기록 보유라는 말만으로 대조 기준을 삼기 어렵다고 한정했다. 첫 답변도 지우지 않고 이 한계를 함께 남겼다.
5. **실제 연결과 소개 단계를 구분했다.** URL만 받았을 때는 확보 인원을 늘리지 않고 제목·입력·업무 응답을 확인했다. 최종 직접 응답은9명이며10명 완료로 보고하지 않았다. 소개 응답의 사적 관계는 원문 보존 외에 고객 안내나 권한·협업·회신 보장 근거로 사용하지 않았다.

## 미완료·한계와 다음 참고사항

- 총10명 중 마지막1명은 직접 연결하지 못했다. 기존 막힌 경로와 자료상 후보 이름을 실제 인터뷰 가능 인물로 올리지 않는다.
- 외부 홍보 계약·원스크립트/캡처, 체험 팜플렛의 유지·결제 문안, 일부 적재 인계 메모·담당, 언론 문의 담당, 긴급 출고 세부와 일부 비용 결정은 인터뷰 수신만으로 확정하지 못했다. 임계표 현행성 등 첨부 판정은 자료팀의 원문·개정 이력 검수 결과를 참고해야 한다.
- 인터뷰 결과는 정책의 최종 권위나 실제 주문 처리 성공을 증명하지 않는다. 모름·미제공·기억 범위·가정 상황을 사실 확정으로 바꾸지 않는다. 수신 자료를 읽을 때도 당시 판과 시행일을 함께 본다.
- 후속 작업은 [승인 정본](../../coordination/contact-expansion.md)과 원문 JSON부터 읽는다. 과거 진행 문서의 중간 수치는 당시 상태다. 발신이 이미 있으면 다시 보내지 않는다. UI 사용은 감독과 현재 소유 담당이 조율한다.

종료 후 사용자가 전달한 최종 운영 상태는 다음과 같으며 **이 담당의 직접 검증 결과가 아니다**. 제출봇 멍멍이 App ID702917은 로컬 LaunchAgent `gui/501/local.ai-top-2026.bot`, 실행 폴더 `/Users/lyuhoyun/.local/share/ai-top-2026`, OpenRouter `google/gemini-2.5-flash`로 유지한다. Vercel은 최종 운영에 채택하지 않았다. 지식266건(255+11) 전체를 프롬프트에 사용하며 검색CLI는 내부용이고 런타임 검색에는 연결하지 않았다. 이 기록 작성 중 서버·설정·지식·코드·제출물은 변경하지 않았다.
