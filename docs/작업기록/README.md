## 최종 상태를 확인할 문서

- [자료목록](../자료목록.md): 원본·판독 요약·출처로 가는 출발점.
- [세컨드브레인](../세컨드브레인.md): 검수된 지식과 내부 검색 도구.
- [로컬 운영](../로컬-운영.md): 실제 운영 프로세스와 점검 방법.
- [다른 컴퓨터 핸드오프](../다른컴퓨터-핸드오프.md): 추후 이전 절차. 대회 종료 시점에는 이전하지 않았다.
- [디브리프 일반 텍스트](../디브리프-붙여넣기.txt): 마크다운 문법을 제거한 제출용 본문.

초기 기록의 당시 미완료 사항을 최종 상태로 해석하지 않는다. 문서 간 수치가 다르면 측정 시점과 직접 확인 범위를 먼저 확인한다. 운영 서버는 작업 페인과 별개의 macOS LaunchAgent로 계속 유지한다.

초기 Vercel p1·p3 기록은 같은 프로젝트와 같은 작업 내용을 상당 부분 공유한다. 이 폴더에서는 각 세션의 회고를 보존하며, 별개의 두 구현·배포 실적으로 합산하지 않는다.

## 종료 기록

각 담당 문서 8개와 감독 기록, 이 색인을 저장했다. 문서의 상대 링크와 알려진 비밀 키 값 미포함을 확인했다. 담당 세션의 완료·대기 상태를 확인한 뒤 대회 작업 공간의 보조 페인 8개(p1·p2·p3·p6·p7·p8·p9·pB)를 닫았다. 감독 페인 p4는 유지했다. 다른 프로젝트 작업 공간과 운영 서버는 종료하지 않았다.
