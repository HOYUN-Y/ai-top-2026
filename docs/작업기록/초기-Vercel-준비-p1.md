# 초기 Vercel 웹훅 준비 (p1, 원래 탭) 작업기록

- 작성: 대회 종료 후, 감독 지시에 따라 이 세션이 직접 작성
- 대상 기간: 2026-10-31(토) 예선 당일 오전. 세션 첫 시각 확인은 **10:37 KST**(`date` 결과)였고, 이후 단계별 정확한 시각은 기록하지 않았다.
- 범위: 이 문서는 **이 세션(p1)이 직접 한 일**만 적는다. 다른 세션이나 감독에게서 전달받은 사실은 「6. 전달받은 최종 상태」에 따로 모았다.

---

## 1. 맡은 목적

1. 대회 공지(카카오톡 채널 챗봇으로 제출, 심사 종료까지 무중단 응답)에 맞춰 **제출용 카카오톡 봇·채널 상태를 확인**한다.
2. 카카오톡 봇 **웹훅 연동 방식을 공식 문서로 확인**한다.
3. 노트북 상태와 상관없이 응답할 수 있도록 **Vercel에 웹훅 서버 초안을 만들어 배포**한다.

## 2. 직접 수행한 작업과 산출물

### 2.1 콘솔·채널 상태 확인 (Chrome, 읽기 위주)
- 처음 연결된 Chrome(Browser 2)은 카카오에 로그인돼 있지 않았다. 사용자가 "다른 크롬"이라고 해서 `switch_browser`로 사용자가 직접 고른 브라우저("HOYUN'S MACBOOK PRO")로 바꿨다. 로그인이나 비밀번호 입력은 하지 않았다.
- 카카오 디벨로퍼스 앱 3개를 확인했다.
  - **App ID 702917 「멍멍이」**: 봇 「멍멍이」가 있었다. 검색용 ID `멍멍이_`, 설명 "AI-top100-예선"이었고, **웹훅은 미등록**, 게이트웨이도 미연결 상태였다.
  - App ID 1290756 「멍멍이주식회사」, 1044844 「kt」: 봇이 없고 생성 폼만 보였다.
- 카카오비즈니스 파트너센터의 채널 「멍멍이」(`_xmaNWX`)를 확인했다.
  - 채널은 공개 ON, **검색 허용 OFF**로 공지 조건과 맞았다.
  - 친구 수는 0명이었다.
  - 챗봇 연결 화면에는 봇 「멍멍이」가 연결돼 있었고 봇 생성일은 2026.10.31이었다.
- 이 과정에서 바꾼 것은 채널홈 안내 팝업을 닫은 것 하나뿐이고, 설정은 바꾸지 않았다.

### 2.2 공식 문서 확인
- 콘솔의 "문서 확인" 링크(`/docs/in/bot/prerequisite`)는 세 번 열어 봤지만 모두 "일시적인 오류"가 떴다.
- 문서 홈 사이드바에서 정상 경로 `/docs/ko/bot/*`(이해하기, 튜토리얼, 설정하기, REST API, 게이트웨이, 웹훅, 에러 코드)를 찾았다.
- 웹훅 문서(`https://developers.kakao.com/docs/ko/bot/webhook`)에서 확인한 규격은 아래와 같다.
  - 수신: `POST {op, t, d}`. `t=MESSAGE_CREATE`일 때 `d`에 `content`, `botUserKey`, `callbackToken`이 들어온다.
  - 수신 후 **1초 안에 2xx(204)로 응답**해야 하고, 본문은 넣지 않는다.
  - 답장은 `POST https://kapi.kakao.com/v1/bot/callback`으로 보낸다. 헤더는 `Authorization: KakaoAK {봇 인증 토큰}`과 `X-Bot-Callback-Token`이고, 본문은 `skillResponse`(v2.0, `simpleText`)다. 콜백 토큰은 **5분 안에** 써야 한다.
  - 웹훅과 게이트웨이는 동시에 쓸 수 없다.

### 2.3 Vercel 웹훅 서버 초안 (산출물)
사용자가 서버는 Vercel 웹훅, LLM은 OpenRouter를 골랐고, 그에 맞춰 만들었다.

| 산출물 | 내용 |
|---|---|
| [api/webhook.js](../../../../../kakao-agent/api/webhook.js) | 204로 바로 응답 → `waitUntil`로 OpenRouter 호출(도구 호출 루프 최대 8회) → 카카오 콜백으로 답장. 처리에 실패해도 사과 메시지를 보낸다. 대화 기록은 사용자별로 최근 20턴을 메모리에 둔다. 커스텀 헤더 검증은 선택(`WEBHOOK_HEADER_NAME/VALUE`) |
| [test/webhook.test.js](../../../../../kakao-agent/test/webhook.test.js) | `fetch`를 모킹한 테스트 4개: 204 응답, 콜백 헤더와 본문, 대화 기록 유지, LLM 실패 시 사과 답장 |
| [package.json](../../../../../kakao-agent/package.json), [vercel.json](../../../../../kakao-agent/vercel.json) | `@vercel/functions` 의존성, `maxDuration: 300` |

- 이 산출물은 저장소(`ai-top-2026`) 밖인 `~/kakao-agent/`에 있다. 위 링크는 이 문서 위치 기준 상대경로다.
- 액션 API(주문 조회, 환불 요청, 담당자 이관)는 명세를 받지 못했다. 그래서 `TOOLS = []`, `ACTIONS = {}`로 빈 자리만 만들었다.
- 배포는 Vercel 프로젝트 `kakao-agent`에 production으로 했다. 계정은 CLI 로그인 계정 `hoyun-y`이고, 프로젝트 별칭은 `kakao-agent-eosin.vercel.app`이다.

## 3. 주요 판단 이유

- **Vercel 웹훅을 권한 이유:** 심사 종료까지 무중단 응답이 조건이었다. 로컬 게이트웨이는 Mac이 꺼지거나 잠들면 멈추는 위험이 있다고 봤다. 이 세션에 Vercel이 이미 연결돼 있었고, 최종 결정은 사용자가 했다.
- **`waitUntil` 구조:** 카카오는 1초 안에 응답해야 하는데 LLM 응답은 그보다 길다. 그래서 "204 먼저 → 콜백으로 답장"이라는 문서의 흐름을 그대로 따랐다.
- **대화 기록을 user/assistant 텍스트로만 저장:** 오래된 기록을 잘라낼 때 tool 메시지가 앞의 tool_calls 없이 남아 요청이 깨지는 일을 막으려는 것이다.
- **모델 ID를 환경변수로 둠:** OpenRouter 모델 ID를 확실히 몰라서 코드에 고정하지 않았다.
- **비밀 값은 사용자가 직접 넣게 함:** 봇 인증 토큰(어드민 키)과 OpenRouter 키는 별도 터미널에서 `vercel env add`로 넣도록 안내했다. 채팅에 비밀 값이 남지 않게 하려는 것이다.

## 5. 미완료·한계

- Vercel 환경변수(`BOT_TOKEN`, `OPENROUTER_API_KEY`, `OPENROUTER_MODEL`)는 넣지 않았다. 사용자가 넣을 차례에서 멈췄다.
- 카카오 콘솔에 **웹훅 URL을 등록하지 않았다.** 그래서 이 Vercel 서버는 실제 메시지를 받은 적이 없다.
- 액션 API는 연결하지 않았다. 명세를 받지 못했다.
- 대화 기록이 인스턴스 메모리에만 있어서, 콜드 스타트나 다른 인스턴스로 요청이 가면 맥락이 사라진다(코드에 `shortcut:` 주석으로 적어 둠).
- 커스텀 헤더 검증은 기본으로 꺼져 있다.
- 잘못 안내한 것:
  - 처음에 카카오 i 오픈빌더 방식(5초 제한, 스킬 JSON 즉답)을 설명했지만, 대회의 "카카오톡 봇"은 다른 상품이었다. 나중에 정정했다.
  - 챗봇beta 메뉴의 '발견' 탭은 ChatGPT 챗봇에 관한 블로그를 근거로 말한 것이었고 사실이 아니었다. 사용자에게 정정했다.
  - "그룹채팅에 넣으려면 '그룹채팅 챗봇 beta 입점 신청'이 필요할 것"이라는 말은 화면 문구만 보고 한 추정이다.

## 6. 전달받은 최종 상태 (이 세션이 한 일 아님, 감독 지시로 전달받음)

- 제출봇은 **멍멍이, App ID 702917**이다. 운영은 **로컬 LaunchAgent `gui/501/local.ai-top-2026.bot`**으로 하고, 실행 폴더는 `/Users/lyuhoyun/.local/share/ai-top-2026`이다.
- LLM은 OpenRouter `google/gemini-2.5-flash`다.
- **Vercel은 최종 운영에 채택되지 않았다.** 즉 이 세션의 산출물은 최종 제출 경로에 쓰이지 않았다.
- 지식은 266건(255+11) 전체를 프롬프트에 넣었다. 검색 CLI는 내부용이고 런타임 검색에는 연결되지 않았다.

이 세션은 위 내용을 직접 확인하지 않았다(지시에 따라 새 검증은 하지 않음).

## 7. 다음에 참고할 사항

- 카카오톡 봇 문서는 콘솔 링크(`/docs/in/...`)가 깨질 수 있다. **`/docs/ko/bot/webhook`, `/docs/ko/bot/gateway`** 경로를 바로 쓴다.
- 채널 검색이 꺼져 있으면 테스트는 채팅 URL(`pf.kakao.com/{채널ID}/chat`)로 들어간다.
- 웹훅 방식에서는 **1초 안에 응답하고 5분 안에 콜백**하는 제약이 핵심이다. 서버리스로 운영한다면 응답 뒤 작업을 이어갈 수단(`waitUntil` 등)과 `maxDuration`을 확인한다.
- Vercel 프로젝트 `kakao-agent`는 **배포된 채로 남아 있다**(환경변수 없음, 웹훅 미등록). 이 세션 이후 누가 등록했는지는 모른다. 쓰지 않는다면 나중에 사용자 판단으로 정리하면 된다. 이 세션은 지시에 따라 건드리지 않았다.
- 대회 개인 토큰은 대화 중에 사용자가 붙여넣었다. 이 세션은 그 값을 어디에도 저장하거나 설정하지 않았다(이 문서에도 적지 않음).
- 여러 Chrome이 연결된 환경에서는 처음 연결된 브라우저가 카카오에 로그인된 브라우저라고 단정하지 말고, 사용자에게 고르게 한다.
