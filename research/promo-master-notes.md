### §2 원장의 성격 (전제)
1. 원장에 없는 코드는 존재하지 않는다. 조회로 나오지 않는 코드는 "찾지 못한" 것이 아니라 없는 것이다. 상담·시스템 어느 쪽에서도 생성할 수 없다(「조합 규정집」 제3조④).
2. 등록·수정 권한은 홍보라뿐이고 조합장 승인 사항이다. 상담(이민준)은 조회·적용만 한다.
3. 만료 코드의 소급 적용은 없다(「인플루언서 계약서」 제3조, 「인플루언서 홍보 게시물」 제1조). 대안은 현행 유효 행에서만 나온다(원문은 "§7"을 가리키지만 유효 행 표는 HTML §9에 있다. 아래 "원문 상호참조 불일치" 참고).
4. 기간 판정 기준 시각은 결제 완료 시각이다. 상담 시각·문의 시각이 아니다.
5. 원장은 기준일을 붙여 읽는다(이 판은 2037-06-30). 등록·수정·중단은 즉시 반영하고, 상태 열은 영업일마다 갱신한다. **기준일이 지난 사본으로 "유효"라고 답하지 않는다.**

## 원문 상호참조 불일치 (원문 그대로 두고 기록만)
- PDF §2③의 "현행 유효 행(§7)": §7은 원인 판정 절차이고 유효 행 표는 HTML §9다.
- HTML §3 "중복 규칙 = §3 매트릭스 참조": 매트릭스는 PDF §5에 있다.
- HTML §3 "1인 한도 … (§6)": §6은 보상 쿠폰이고 사람 단위 판정은 HTML §8에 있다.
- HTML §4-2 "§2 코드 원장과 별 표": 코드 원장은 HTML §4다(§2는 PDF의 원장 성격).
- 규정 이름 표기: 이 문서는 「판매 환불 규정집」 제4·13조, 위임표는 「판매·환불 규정」 제13조(출고 전 수량 축소 차액)를 쓴다. 같은 문서인지, 조문 번호가 같은 내용을 가리키는지는 원문 없이 판단하지 않는다.
