# 운영 규정 추가분·과거 행사 목록 교차 검수

root가 knowledge의 `research/privacy/rules-additions.json`을 이미 읽은 조합 운영 규정 제4·5·7·19~23·26조와 대조했다. `research/event-history/facts-candidate.json`은 XLSX 원본 4시트의 XML 셀을 독립 재추출해 `records.json` 전체 셀과 일치함을 확인하고 행별 의미를 대조했다.

- 운영 규정 신규7건, 과거 행사 신규4건 반영으로 runtime210→221건.
- 적립금 소멸·안내 수단과 쿠폰 반복 발급 보류는 기존 `membership-benefits`, `promo-person-limit`에 추가해 중복 항목 생성을 피했다. API22는 주문 복구이며 적립금 복원과 다르다.
- 출하 기준 미달 금지는 예약 접수 자체의 금지로 확대하지 않았다. 원문의 특정 수확일 제한·품질 미달 실제 출하 금지만 반영했다.
- 행사 ID는 원본의 `EV-2037-01`~`06`을 보존했다. 후보의 `EV-01` 축약을 통합 시 원래 값으로 바꿨다.
- 5/30 직거래 매대와 6/23~25 수확축제는 별개 오프라인 행사다. 체험 예약·온라인 주문과 섞지 않는다.
- 과거 미성년 명단 사전 수집은 현재 수집의 근거가 아니다. 명단의 실제 값은 자료에 없고, 보유 매체·항목 종류·미파기 기록만 있다. 파기 완료나 날짜를 약속하지 않는다.

신규 인물·연락처는 없고, 「조직 관계도」 §7이 추가 참조문서 단서다. 이 검수는 코드·실제 개인정보 삭제·액션 실행을 검증한 것이 아니다.
