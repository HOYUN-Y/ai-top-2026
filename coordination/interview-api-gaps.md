## 후보6개

### 1. 박민아 — 신규 채널 우선·대화 가능 확인 전 보류

**정확 문구 (73자):**

> 기사님이 직접 운송하신 갯마을 냉동 상품에 배송 문제가 생기면, 언제 누구에게서 받아 누구에게 넘겼는지 어떤 기록으로 확인하시나요?

- 목적·사례/자료 근거: 사용자의 새 박민아 직접 운송 질문 요청. 공개 사례 Y-16의 송장/인수 구분은 참고하되 애플망고 사건을 박민아 담당으로 옮겨 가정하지 않음. C31은 재질문 결론이 아닌 기존 참고 자료.
- 담당자 지식범위: 직접 운송한 자기 담당 구간·인수 상대·인계 상대·시각·기록을 먼저 확인한다. 환불·정책 승인이나 교동 전체 운행을 맡는다고 전제하지 않는다.
- 중복 제외 근거: 구방만 R4Q1은 문자 수신, R5Q1은 구방만 자신의 통상 기록이었다. 박민아 본인에게 직접 운송한 건의 확인 근거를 물은 적은 없다. 6/24·온도 상승·문자 발송을 질문에 넣지 않아 C31 내용에 동의를 유도하지 않는다.
- 미확보 인물 연결 단서: 첫 소개자가 홍이장이며, 답에서 새 인수/인계 상대가 실명으로 나오면 실제 관계의 새 경로가 된다. 아직 누구를 새 인터뷰 대상이라고 확정하지 않는다.
- 상태: 미승인·미발송.

### 2. 구방만 — 높음

- 상태: 미승인·미발송.

### 3. 이민준 — 높음

**정확 문구 (96자):**

> 고객이 수박을 먹고 배탈이 났다며 병원비를 요구하지만 상품 하자는 아직 확인되지 않았습니다. 검토 요청을 어떤 내용으로 남기고, 접수번호와 회신 기한은 어떻게 안내하시나요?

- 상태: 미승인·미발송.

### 4. 홍보라 — 중간

- 미확보 인물 연결 단서: 게시/수정 담당이 새로 실명 등장할 때만 연결 단서. 홍보걸이 다시 나오면 과거 채널 모름 사실을 함께 남긴다.

- 상태: 미승인·미발송.

## 검토 요청과 제한

실제 발송 우선순위는 root가 확정한다. 박민아는 대화 가능 여부가 해결되기 전 발송 불가이며, 나머지는 구방만/이민준 업무 근거 공백 우선으로 추천한다. 이민준 후보3건·다른 각1건으로 전부 승인되어도 라운드 총6/10·인당5회 이내다. 다만 이는 후보의 분포일 뿐 승인·질문 카운터에 가산하지 않는다. 새 첨부에 답이 이미 있으면 생략 근거를 기록하고 기존자료 확인으로 끝낸다. API 실행이나 개인정보 조회는 하지 않았다.
