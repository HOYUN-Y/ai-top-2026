## 남은 사항·과장 금지

- root가 사용자에게 동일 최종 질문 **직접 1회 발송**을 요청했고, 발송되면 runtime 로그로 확인할 예정이다. **현재는 발송·응답 증거를 받지 않았으므로 성공으로 기록하지 않는다.** 이 후속은 검수자의 재전송이 아니다.
- 현재 runtime은 action ON이지만 **프로세스 운영·기본 왕복 검증 외 실제 업무 POST/reset은 0회**다. 실제 주문 처리·실액션 접수 성공·심사 성공으로 확대하지 않는다.
- 실모델 E2E는 소수 합성 표본·모의 액션이다. 지연은 카카오 제외이며 p95가 아니다. 최신 KB255건 전체 정합/실모델 응답, 실제 오디오 인식, 모든 예외 업무를 검증했다고 하지 않는다.

- 대화·중복 기록·누적 호출의 지속 저장은 미구현이며 재시작 시 초기화된다. 새 인프라나 보안 예외 변경을 요구하지 않았다.
