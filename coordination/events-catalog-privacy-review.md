# 체험·상품 카탈로그·개인정보 규정 교차 검수

감독(root)이 knowledge 담당의 후보를 원문과 독립 대조했다. 체험 B55 이미지 2장, 카탈로그 HTML 전체를 정적 추출한 본문·표, 개인정보 처리방침 전체, 조합 운영 규정 7쪽 추출문, 제3자 보호 B18 이미지 4장을 확인했다. 코드 검수 적합 판정과는 별개다.

## 반영

- 체험 신규 5건, 상품 카탈로그 신규 16건, 개인정보 신규 18건: runtime 154 → 193건. 중복되는 확정 단계 수집 항목·당도·중량·환불 계좌 규칙은 기존 사실에 추가했다. 세부 ID는 [병합 기록](latest-knowledge-merge.json).
- 체험에서는 개별 참가자 명단 금지, 가예약/최종확정 구분, 30명/개방일 약40명, 우천 시 전날17시 통보 대상이 고객 측 인솔 책임자임을 확인했다. 명단 관련 일반 개인정보 문구와 체험 특칙의 적용 범위를 보존했다.
- 카탈로그의 고객 공개 범위·라인별 당도 기준·입수 분모·가격·보관·시즌 상태를 원문 표와 대조했다. 원문의 품목 12/실제13개, SKU33/실제34행, 농산10/실제11개 불일치는 고치거나 단정하지 않았다. 날짜별 원인은 다른 날짜로 확대하지 않는다.
- 개인정보의 인증 방향·주문 귀속·제3자 비공개·연락 중계·대리 요청·미성년 정보·보유기간을 확인했다. B18 사진의 표는 원근 때문에 기울어져 있으며 잘못된 행 대응으로 판정하지 않았다.

## 반영 시 보정

1. `B18-0N.png`라는 존재하지 않는 자리표시 출처를 실제 원본 4장 경로로 바꿨다.
2. '이 문서에 요금이 없으므로 안내 금지'는 '이 문서만으로 확정하지 않음'으로 한정했다. 공개 가능한 항목을 영구 금지하지 않는다.
3. 라벨의 '국내산(제주)'와 카탈로그의 '제주 교동마을'은 상세도 차이로 보존하며 원산지 자체의 모순으로 만들지 않았다.
4. 확보된 개인정보·정기배송·과거 행사 목록을 계속 미확보라고 하는 표기는 정정했다. 구독·행사 개별 내용의 별도 검수는 유지한다.
5. R6 답변을 반영해 인원 감소 정산의 김청년→고길동→이민준 순환 질문을 종료했다. 금액은 추정하지 않는다.
6. 한 원문에만 적혔다는 사실은 불확실성 자체가 아니므로, 인증 정의·3회 상한 등의 메타 주석을 불확실 칸에서 제거했다.

## 남은 범위

조합 운영 규정의 적립금·도매·픽업 등 추가 규칙은 knowledge 담당이 별도 후보를 준비한다. 사업자정보의 실제 공시값, 가격 정책 시트, 부분환불 임계표, 에스컬레이션 3레인 원문 등은 아직 보완 대상이다. 이 병합은 실제 액션·카카오톡 운영 검증을 의미하지 않는다.
